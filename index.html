关于本系统

智学 · 自适应刷题系统 — 面向高校学生的轻量化自适应复习引擎。纯前端实现，单文件运行，数据保存在本机浏览器。
系统为每道题维护一个"掌握度"分数。答错后掌握度下降，并按记忆规律安排复习。与普通遗忘曲线工具不同的是，本系统做了三点改良：
① 题型难度分档——判断题记忆负担小、间隔短；多选/长题干概念题负担重、间隔长；
② 动态稳定度——复习间隔不是写死的（20分/1天/2天…），而是根据每题答对/答错动态伸缩；
③ 知识点连带激活——同一知识点的题"一错牵连一串"，带动关联复习。
智能模式据此计算每道题的抽取权重，优先推送"最该复习的题"，而不是平均随机。
每题可标注所属知识点。系统按知识点聚合答题数据，算出加权正确率作为掌握度，用进度条可视化，并自动标记薄弱知识点，让复习有的放矢。
模拟测试模式按知识点分布与掌握度自动抽题组卷，尽量做到覆盖全面、难易合理，模拟真实考试。
导入题目时可以给题库命名（如"马原""形策"），不同科目的题分开存放、分开练习，不会混在一起。刷题时可选择练某个题库或全部题库。已命名的题库可以整组删除。
每次出题时，选择题的选项顺序都会重新打乱（判断题的"对/错"保持不变）。这样即使你记住了"答案在第 C 个"，下次顺序变了也无法蒙对，必须真正记住知识点内容。
练习过程中会实时记住你的进度。如果不小心关掉了页面，下次打开时会弹窗问要不要继续上次的练习：选"继续"就回到退出时那道题（连选项顺序都不变），选"重新开始"就回到首页重新选题库和模式。一轮练习做完后，进度自动清零。
遇到不会的题，可以点"🤔 不会"按钮直接看答案（按答错处理，进错题本）。如果蒙对了，答对界面有"其实我是蒙的"按钮——点它就按错题处理。因为蒙对并不代表真的掌握，诚实标记后系统会重点复习这些题，避免"假掌握"。
导出的题库文件（JSON）可以直接发给同学，同学导入就能用。同一份系统文件发给多个同学，各自在电脑/手机上打开，各自的数据互不干扰——适合一个班共用一套题库。注意：分享的是题目，各自的答题记录仍在各自设备上。
同一个题库内，如果导入的题目题干、选项、答案都相同（选项先后顺序不同也算相同），会自动跳过、不会重复收录，并提示"跳过 N 道重复题"。这样同一个题库反复导入也不会翻倍。注意：只在同一题库内查重，不同题库（如马原、形策）之间互不影响。
所有数据（题库、答题记录、错题、掌握度）保存在浏览器 localStorage 中，不上传服务器，隐私安全。导出 JSON 即可备份或分享题库。
